# KickResume Browser Extension

## Overview

This is a chrome extension for the purpose of automatically saving your progress on kick.com videos so it resumes from where you left off

## Features

- **Multi-language Support:** de, en, es, fr, it, ja, ko, pt-br, pt-pt, ru, zh-CN.
- **Customizable Settings:**
  - `Show Progress Bar`: Toggles the visibility of a progress bar.
  - `Show Now Playing Tag`: Displays a tag indicating what's currently playing.
  - `Auto Close Chat`: Automatically closes the chat interface under certain conditions.
  - `Auto Close Sidebar`: Automatically closes the sidebar under certain conditions.
  - `Pause On Click`: Automatically pauses playback when clicking inside video frame (Like youtube).

## Installation

### From the Chrome Web Store (or other extension stores)

You can install the extension directly from the Chrome Web Store:
[Kickresume on Chrome Web Store](https://chromewebstore.google.com/detail/kickresume/cclmmfbfmjjeafmilojlhmdekmagonmb)

## Development

This project uses [WXT](https://wxt.dev/) for building browser extensions, [React](https://react.dev/) and [Tailwind](https://tailwindcss.com/) for the user interface.

### Prerequisites

- Node.js
- pnpm (or npm)

### Setup

1.  **Clone the repository:**
    ````bash
    git clone https://github.com/Hugo-Farias/kickresume.git
    cd kickresume    ```
    ````
2.  **Install dependencies:**
    ```bash
    pnpm install
    ```

### Running in Development Mode

```bash
pnpm dev
```

This will build the extension and watch for changes. You can then load the unpacked extension into your browser as described in the "Manual Installation" section, pointing to the `.output` directory generated by WXT.

### Building for Production

```bash
pnpm build
```

This will create a production-ready build in the `.output` directory.
